# 0.1.0 — 첫 공개 릴리스

## 포함

- Showreel 음악 모션그래픽과 이전 CD 호출 호환 경로
- Showreel 기반 M/V 기획·이미지·편집 스킬
- JIZURA 음악 스튜디오와 로컬 HTML 편집 흐름
- 네 제작 방식의 실제 샘플·설명·음원 재생·선택·검수용 공통 HTML 제작실
- Codex·Antigravity App/IDE·Antigravity CLI 설치 경로와 이미지 공급자 연결
- 스킬 설치·Release 확인·로컬 수정 보존 업데이트 도구
- Showreel MV의 image_gen/Nano Banana 기본값과 별도 요청 없는 유료 API 사용 금지
- Road Music CLI의 음악 생성 후 모션그래픽 handoff 문서

## 검증 범위

- manifest의 6개 스킬 경로·문서 링크·최근 4개 샘플 미디어 해시를 확인했습니다.
- 업데이터 설치·로컬 수정 보존·롤백·Release ZIP 검증과 HTML 제작실·JIZURA·Showreel 프리셋의 관련 검사를 통과했습니다.
- 엔진·모델 설치, 실제 청취 품질, 모든 운영체제의 렌더 결과는 이 릴리스에서 보증하지 않습니다.

## 제외

- LTX 2.5 기반 `road-music-mv` 감독 스킬과 모델
- 개인 전체 음원, 토큰, 절대 사용자 경로, 전체 생성 프로젝트와 전체 렌더 산출물(공개 형식 샘플 발췌 제외)
