# 0.1.1 — 실제 사용 검수 보완

## 달라진 동작

- 프로젝트·Antigravity에 설치한 스킬을 읽고도 전역 구버전 helper나 현재 폴더의 잘못된 상대 경로를 실행하던 안내를 수정했습니다. 실제 읽은 `SKILL.md` 폴더를 기준으로 실행합니다.
- HTML에서 선택한 SKIP이 제작 방식 전환과 결과 새로 고침 후에도 유지됩니다. 처음에는 여전히 네 표시 항목을 직접 선택하거나 SKIP해야 합니다.
- 음악을 들으며 제작 방식과 검수 화면을 바꿔도 같은 음원의 재생 위치·상태를 보존합니다. 이름이 같은 다른 음원을 업로드하면 실제 파일 해시로 구분해 플레이어를 갱신합니다.
- 단계별 `publish`가 검수 목록 전체를 교체하는 스냅샷임을 명시했습니다. 유지할 스토리보드·자막·부분 영상도 후속 manifest에 함께 넣습니다.
- 주황색 어절 강조에 필요한 그루브 다이얼·실제 어절 시각 조건, 표시 제목 전달, 리듬 캔버스의 이미지·썸네일 제작 단계를 명확히 했습니다.
- 필수 어절 추적은 `plan/create --require-word-timing`으로 보존하고, 표시할 가창 큐의 `words`가 없으면 프로젝트 생성 전에 알립니다. 일반 줄 자막과 가창 전 인트로 미리보기는 기존대로 지원합니다.

## 설치와 사용

현재 스킬 설치 부모를 `--target`으로 지정해 명시적으로 업데이트합니다. 저장소·Release의 전체 묶음 경로인 `--source`와 설치 대상은 서로 다릅니다. 기존 사용자 수정본을 덮어쓰거나 음악·모델을 이동하지 않습니다.

CLI의 `motion:*`에서 갱신된 설치본을 사용하려면 Road Music CLI 0.1.2 이상을 사용합니다. 스킬 사용 시 한 번만 업데이트를 확인하며 정기 알림·자동 설치는 등록하지 않습니다. 기본 이미지 도구와 별도 요청 없는 유료 API 차단 정책은 유지합니다.

## 검증과 범위

- Studio 회귀 테스트 16개, updater·Release 테스트 13개, Showreel 프리셋 테스트 74개를 통과했습니다.
- 실제 브라우저에서 미응답 상태·SKIP 유지·음원 재생 위치 보존·선택 저장을 확인했습니다.
- 독립 사용 검수와 문서·실행 경로 검토를 수행했습니다. 이미지·음악 생성, 모델 설치, 새 영상 렌더와 가창 청취 품질 검수는 실행하지 않았습니다.
