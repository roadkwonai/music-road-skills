# 0.1.1 — 한 페이지에서 제작과 검수

## 달라진 동작

- 반복 호출마다 HTML 탭이 늘어나던 경로를 수정했습니다. Ego의 기존 Road Music 페이지를 재사용하고, 같은 주소는 다시 로드하지 않으며 필요한 스킬 화면으로만 이동합니다. 완료 후 남긴 페이지도 다시 연결합니다. 사용자 생성 공간을 가져오거나 제어 오류를 새 탭으로 우회하지 않습니다.
- 공통 제작실·카탈로그·선택기·JIZURA·가사 검수 HTML에 DESIGN.md와 Paperlogy를 적용했습니다. 스킬 설치본에도 디자인 계약·9개 글꼴·OFL·공통 메뉴가 포함됩니다.
- 음원·원가사·완성 영상의 재생·다운로드를 별도 영역으로 제공하고, 네트워크 실패 안내·중복 제출 방지·모바일 넘침·JIZURA 페이지 복귀 설정 보존·손상 음원 거부를 보완했습니다.
- JIZURA 가사 잘림·줄바꿈·잔상 검사와 확정/추정 시각 구분, Showreel 곡별 새 native 연출 경로를 포함했습니다. HTML UI 글꼴과 곡별 영상 미술은 구분합니다.
- 최신 ‘어디든 좋아’와 ‘내일로 달려’ 샘플을 반영했습니다. 찾지 못한 ‘당신이 참 좋아요’ CD 완성본 대신 기존 CD 예시를 명시적으로 유지합니다.
- 업데이트 도구는 관리 스킬 6개가 모두 포함됐는지 검사하고 공용 HTML·디자인·폰트·가독성 자산을 함께 설치합니다. 사용자 수정본 거부·백업·롤백 정책을 유지합니다.

- 프로젝트·Antigravity에 설치한 스킬을 읽고도 전역 구버전 helper나 현재 폴더의 잘못된 상대 경로를 실행하던 안내를 수정했습니다. 실제 읽은 `SKILL.md` 폴더를 기준으로 실행합니다.
- HTML에서 선택한 SKIP이 제작 방식 전환과 결과 새로 고침 후에도 유지됩니다. 처음에는 여전히 네 표시 항목을 직접 선택하거나 SKIP해야 합니다.
- 음악을 들으며 제작 방식과 검수 화면을 바꿔도 같은 음원의 재생 위치·상태를 보존합니다. 이름이 같은 다른 음원을 업로드하면 실제 파일 해시로 구분해 플레이어를 갱신합니다.
- 단계별 `publish`가 검수 목록 전체를 교체하는 스냅샷임을 명시했습니다. 유지할 스토리보드·자막·부분 영상도 후속 manifest에 함께 넣습니다.
- 주황색 어절 강조에 필요한 그루브 다이얼·실제 어절 시각 조건, 표시 제목 전달, 리듬 캔버스의 이미지·썸네일 제작 단계를 명확히 했습니다.
- 필수 어절 추적은 `plan/create --require-word-timing`으로 보존하고, 표시할 가창 큐의 `words`가 없으면 프로젝트 생성 전에 알립니다. 일반 줄 자막과 가창 전 인트로 미리보기는 기존대로 지원합니다.

## 설치와 사용

현재 스킬 설치 부모를 `--target`으로 지정해 명시적으로 업데이트합니다. 저장소·Release의 전체 묶음 경로인 `--source`와 설치 대상은 서로 다릅니다. 기존 사용자 수정본을 덮어쓰거나 음악·모델을 이동하지 않습니다.

이 릴리스는 스킬 묶음이며 Road Music CLI 앱 자체를 업데이트하지 않습니다. 기존 CLI의 스킬 탐색이 구버전 경로에 고정됐다면 설치된 각 스킬의 실제 helper 경로를 사용합니다. 스킬 사용 시 한 번만 업데이트를 확인하며 정기 알림·자동 설치는 등록하지 않습니다. 기본 이미지 도구와 별도 요청 없는 유료 API 차단 정책은 유지합니다.

## 검증과 범위

- updater·Release 검사 16개, 제작실 서버 검사 18개, 공통 디자인·완성 파일 검사 14개, JIZURA 서버·프로젝트 검사 19개, Showreel 프리셋·native·선택기 검사 61개를 통과했습니다.
- 연동 소스 CLI의 자동 검사 260개를 통과했습니다. 일반 자동 검사는 실제 브라우저를 열지 않도록 분리했습니다.
- Ego에서 CLI 연속 3회 실행 시 동일 탭과 동일 문서가 유지되는 것, 같은 탭에서 카탈로그와 JIZURA 편집기로 이동하는 것을 확인했습니다.
- 관리 스킬 6개와 공용 자산을 검증했습니다. 모델 설치·사용자 전곡 재렌더·다른 운영체제 실기·전곡 가창 청취 품질을 이 릴리스로 인증하지 않습니다.
