# 릴리스 노트

각 GitHub Release는 `release/YYYY-MM-DD-title.md` 노트와 같은 버전을 사용합니다. 최신 묶음 버전은 루트의 `VERSION`과 `manifest.json`에서 확인합니다.

| 버전 | 날짜 | 노트 |
| --- | --- | --- |
| 0.1.0 | 2026-10-20 | [버전 초기화 릴리스](2026-10-20-version-reset-0-1-0.md) |

이전 릴리스 노트 원문은 [보관 기록](../docs/release-history/)에서 확인할 수 있습니다. 현재 `release/`에는 배포 검증에 사용하는 릴리스 노트만 둡니다.
