# 0.1.0 — 버전 초기화·수정본 재배포

## 포함

- 사용자 승인에 따라 현재 Music Road Skills 묶음의 수정본을 같은 `0.1.0`으로 다시 배포합니다. 이 재배포는 2026-10-20 버전 초기화의 명시적 예외이며, 이후 정식 릴리스에 같은 버전을 다시 쓰는 일반 규칙이 아닙니다.
- Showreel·JIZURA·영상 제작실·저장공간 관리·제작 기록·업데이트 스킬과 동봉 문서·HTML 자산을 같은 묶음 버전으로 관리합니다.
- 스킬 업데이트 확인은 미설치 대상, 공개된 정식 배포 없음, 공개 버전보다 높은 설치·소스 버전을 구분해 기록하고 화면에 표시합니다. 어느 상태에서도 자동 다운그레이드나 자동 설치는 수행하지 않습니다.

## 설치 안내

- 기존 `0.1.1` 설치본은 버전이 낮아지는 초기화 릴리스이므로 자동 업데이트 대상이 아닙니다. 진행 중인 작업과 로컬 수정본을 보존하고 새 빈 설치 대상으로 설치합니다.
- 같은 `0.1.0` 번호라도 이전 배포 파일과 동일하다고 가정하지 않습니다. 설치 전 Release의 `SHA256SUMS.txt`로 새 아카이브를 확인합니다.
- 이후 릴리스는 새 버전·새 태그·새 릴리스 노트만 사용합니다.

## 검증 범위

- `VERSION`, `manifest.json`, 릴리스 태그와 릴리스 노트의 버전 일치를 검사합니다.
- allow-list 묶음 생성과 SHA-256 체크섬 검증을 실행합니다.

## 제외

- 개인 음원·영상 결과물·프로젝트·로컬 SQLite 기록·토큰·대형 모델은 묶음과 Release asset에 포함하지 않습니다.
