영상 제작실

음원과 표현 방식을 고르고 화면 표시 설정을 제작 요청으로 저장합니다.

준비 중…

상태명령 참고CCM 전문 가이드제작실 사용 가이드

  1. 11단계 음원 확인사용할 원음 듣기
  2. 22단계 방식·스타일형식 샘플로 비교
  3. 33단계 화면 표시4항목 선택 또는 SKIP
  4. 44단계 요청 저장선택한 스킬에 전달
  5. 55단계 제작 후 결과 확인재생 · 검수 · 다운로드

1~4단계에서 제작 설정을 저장하면 선택한 스킬이 제작을 이어갑니다. 완성 뒤에는 내 작업물에서 결과를 확인하세요.

1. 음악 확인

해야 할 일
제작에 쓸 원음을 재생해 확인하거나 새 파일을 연결합니다.
완료 후
이후 선택과 결과는 이 원음을 기준으로 기록됩니다.
음원 연결 도움말
다른 음원을 연결할 때

이전 곡의 가사 시각과 제작 결과는 새 곡에 그대로 적용할 수 없습니다. 사용할 원음이 맞는지 먼저 들어 보세요.

입력 음원

프로젝트에 등록된 원음을 재생합니다. 여기서 고른 새 파일은 프로젝트 입력으로 안전하게 복사됩니다.

지원되는 오디오 파일만 연결합니다. 연결 후 이전 결과는 다른 원음의 결과로 표시될 수 있습니다.

2. 제작 방식과 스타일

해야 할 일
결과 형식과 스타일을 고릅니다. 곡별 새 연출은 프리셋 대신 가사·분위기를 기준으로 기획합니다.
완료 후
선택한 방식과 스타일이 제작 요청에 저장됩니다.
스타일 선택 도움말
미리보기 크기목록에서는 필요한 샘플만 펼쳐 봅니다.
작업 호스트 제작을 이어갈 도구를 기록합니다. 이미지나 영상을 이 페이지에서 자동 생성하지 않습니다.

표현 스타일

3. 화면 표시

해야 할 일
스펙트럼·목록·곡 이름·채널명을 표시하거나 숨깁니다. SKIP은 기존 값을 바꾸지 않습니다.
완료 후
저장할 화면 정보가 정리됩니다.
표시 설정 도움말

4. 제작 요청 저장

해야 할 일
선택한 원음·방식·스타일·화면 표시를 저장합니다.
완료 후
다음 제작 스킬이 저장된 요청을 읽어 작업을 이어갑니다.
저장하면 다음 제작 단계로 전달됩니다

선택한 스킬이 실제 제작을 진행한 뒤 완성 파일이 등록됩니다. 결과는 내 작업물에서 확인하세요.

네 화면 표시 항목을 모두 고르거나 SKIP한 뒤 저장합니다. 실제 영상 제작은 다음 단계에서 진행합니다.

완성 파일 등록 전 확인

manifest JSON을 붙여 넣으면 추가·제거·유지될 파일만 미리 계산합니다. 이 확인은 파일을 등록하거나 기존 결과를 바꾸지 않습니다.


    

  




  
제작 단계와 선택 기준

  

    
1. 원음과 원가사를 먼저 확인
입력 음원을 재생해 이번에 만들 곡이 맞는지 확인하세요. 다른 음원을 연결하면 이전 곡의 가사 시각과 결과를 새 곡에 그대로 적용할 수 없습니다.
이곳은 음악 파일을 연결하는 화면입니다. 원가사 파일은 제작을 이어갈 AI에게 함께 지정하고, 승인한 원문을 유지하도록 요청하세요.

    
2. 어떤 영상을 만들고 싶은가요?

      
Showreel CD
앨범 이미지와 회전 CD로 음악을 오래 감상하는 플레이리스트. 잔잔한 곡이나 표지 중심의 화면에 잘 맞습니다.

      
Showreel MV
가사와 감정 흐름을 장면·카메라 편집으로 표현하는 전곡 MV. 인물·배경·스토리보드를 함께 기획합니다.

      
JIZURA 음악 스튜디오
가사와 비트에 반응하는 키네틱 타이포그래피. 여러 추천을 비교하고, 전용 편집기에서 구간별 스타일과 효과를 조절합니다.

      
Showreel 모션그래픽
곡의 분위기와 리듬에 맞춘 이미지·기하 그래픽·모션. 곡별 새 연출 또는 등록 프리셋으로 시작합니다.

    
잔잔하거나 가사가 긴 곡은 단일 스타일로 시작해 보세요. 에너지 차이가 큰 곡은 벌스·후렴·브리지별 조합을 제작 AI에게 요청할 수 있습니다. 카드 영상은 다른 곡의 형식 예시입니다.

    
3. 화면에 무엇을 표시할까요?
스펙트럼·곡 목록·현재 곡명·채널명을 각각 정합니다. 표시는 넣기, 표시 안 함은 숨기기, SKIP은 저장된 값을 유지하기입니다.
채널명을 쓰지 않으려면 SKIP을 고르세요. 판단을 다음 제작에 맡기려면 모든 항목 SKIP으로 전달할 수 있습니다.

    
4. 저장 후에는 어떻게 진행하나요?
선택·제작 요청 저장을 누르면 현재 원음과 설정이 제작 요청으로 저장됩니다. 다음 AI 제작 스킬이 요청을 읽어 기획·가사 싱크·렌더 작업을 진행합니다.
JIZURA는 전용 편집기에서 가사와 비트, 스타일을 조절합니다. 요청 저장과 실제 영상 생성은 별도 단계이며, 저장 성공 문구에서 다음 작업을 확인할 수 있습니다.

    
5. 완성 결과 확인과 다운로드
제작이 끝나면 내 작업물에서 해당 음악을 고르세요. 상세의 영상·음원·가사/자막·스토리보드·검수/제작 기록 메뉴로 같은 곡의 버전을 비교할 수 있습니다.
가사와 SRT는 실제 등록된 파일을 각각 내려받습니다. 음악 그룹 ZIP은 사용한 원음과 등록된 완성 파일을 함께 담습니다.
