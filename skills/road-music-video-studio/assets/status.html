조회 전용

이 페이지는 서비스를 시작하거나 설치·생성·렌더·업데이트를 실행하지 않습니다. 기존 서비스가 연결된 경우에만 준비 상태와 작업 상태를 읽습니다.

CLI와 서비스

로컬 schema·버전은 직접 확인하고, 서비스는 자동 시작 없이 상태만 확인합니다.

기존 서비스의 준비 상태

연결된 서비스가 있을 때만 엔진·도구·대기열·영상 상태를 읽습니다.

저장공간 검사 항목

현재 설치에서 사용할 수 있는 정리 검사만 표시합니다. Git 객체 분석은 Git 항목을 직접 선택할 때만 실행합니다.

제작 스킬 준비

설치 경로와 실행 진입점 파일의 존재만 확인합니다. 모델 설치나 제작 가능 여부를 보장하지 않습니다.
