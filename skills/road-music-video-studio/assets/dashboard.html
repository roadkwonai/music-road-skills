전체 제작 성능

평균·추이는 성공한 작업 기준입니다. 총 소요 시간에는 측정된 실패·취소 작업도 포함하며, 단계 시간을 중복 합산하지 않습니다. 미측정 값은 0으로 가정하지 않습니다.

작업 유형별 비교

같은 제작 영역·작업 유형·엔진·모델의 성공 작업을 비교합니다. 표본 수가 적으면 판단 근거가 제한됩니다.

평균보다 오래 걸린 작업

동일 작업 유형에서 비교 가능한 성공 표본이 3개 이상일 때, 다른 표본 평균의 1.5배를 초과한 실제 측정 작업만 표시합니다.

프로그램·스킬 버전 상태

현재 설치 상태와 마지막 업데이트 확인 결과를 기록합니다. 각 항목에서 업데이트를 확인하고 실행합니다. 설치 방식에 따라 재시작 또는 새 CLI 경로 적용이 필요합니다.
