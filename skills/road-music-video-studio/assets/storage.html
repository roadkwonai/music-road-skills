관리 상태와 추적 범위

활성화된 검사만 실행합니다. 연결되지 않은 폴더와 파일은 삭제 대상에 넣지 않고, 이유를 확인한 뒤 프로젝트에 연결하거나 별도 정리 계획으로 처리합니다.

검사 항목은 설치 환경에 필요한 경우에만 활성화됩니다. Git 저장소가 없으면 Git 검사는 비활성화됩니다.

음악별 제작 작업

직접 제작한 음악을 기준으로 영상·애니매틱·작업 버전을 묶어 표시합니다. 이름을 열면 하위 프로젝트와 M/V 정리 대상을 확인할 수 있습니다.

선택한 음악 작업의 보존·정리 세부 설정

보존과 자동 정리 정책

편집 중에는 이력을 보존합니다. 완료·보관 상태에서는 기간이 지난 재생성 캐시만 자동 정리됩니다.

선택한 작업의 캐시 정리

기본 정리는 재생성 가능한 캐시만 대상으로 합니다. 중간본·히스토리는 보존 해제 후 항목을 직접 선택해야 합니다.

보호

원음, 입력, 완성 manifest, 승인 자산, 현재 참조 파일과 핀한 항목은 삭제 대상이 아닙니다.

재생성 파일 등록

분류에 맞는 .roadmusic/cache/, .roadmusic/intermediate/, .roadmusic/history/ 내부 상대 경로만 등록할 수 있습니다.

선택한 작업의 관리 이력

정책·정리뿐 아니라 음악, 제목, 가사, 영상 설정과 검수 의견 변경을 SQLite 이력으로 확인합니다. 같은 값으로 다시 저장하면 새 이력을 만들지 않습니다.

    정리 실행 이력
      기타 정리 대상·고급 관리

      음악 작업에 직접 속하지 않는 공용 캐시, 이전 설치 검증본, Git 미참조 객체와 원시 작업 폴더 목록은 여기에서만 표시합니다.

      완성본 전용 구조로 정리

      검증된 완성본만 Output/음악/프로젝트/년월일-시분초에 남기고, 기존 테스트·미연결 제작 폴더는 계획으로 확인한 뒤 정리합니다.

      구조 상태를 확인하는 중…

      현재 앱의 과거 공용 영상 캐시

      프로젝트별 캐시와 분리된 이전 앱 분석 자료입니다. 앱이 유휴 상태일 때만 공개 CLI로 확인합니다.

      점검 버튼을 눌러야 현재 앱 프로필의 과거 공용 캐시를 조회합니다.

      작업 폴더 정리

      소스 폴더 전체를 먼저 스캔한 뒤 Git 미참조 객체, 과거 설치 검증 복제본, 과거 제작·참조 자료, 최종본 외 제작 자료를 분리해 확인합니다.

      스캔·보호 범위

      심볼릭 링크는 따라가지 않고 보호합니다. 현재 참조, reflog, 모든 worktree와 스테이징 상태도 유지합니다. 과거 제작·참조 자료와 최종본 외 제작 자료는 자동 일괄 정리에는 포함하지 않습니다. Git 정리가 끝날 때까지 다른 Git 작업을 하지 마세요.

      전체 스캔이 완료된 뒤에만 정리 후보를 미리 볼 수 있습니다.

      최근 정리 이력

        과거 렌더·검증 캐시 찾기

        제작 근거가 확인된 렌더 캐시와 지원되는 과거 패키지 검증 ZIP을 표시합니다.

        정리를 실행할까요?

        계획을 만든 뒤 파일·정책·보호 상태·작업 잠금이 바뀐 항목은 삭제하지 않습니다.

        저장공간을 안전하게 관리하는 방법

        음악별 작업에서 필요한 원음·완성 파일은 보호합니다. 자동 일괄 정리는 재생성 가능한 캐시와 검증된 잔재만 대상으로 합니다.

        M/V 프로젝트 전체 정리는 해당 음악을 연 뒤 영상·애니매틱 삭제를 직접 선택하고 실제 목록을 확인할 때만 실행합니다.

        저장공간 관리 가이드에서 자세히 보기

        추적·미연결 자료를 읽는 방법

        음악·영상·가사·제목·검수와 저장공간 정책의 변경은 SQLite에 짧은 전후 값과 시각으로 기록합니다. 원문 파일 자체는 프로젝트의 정식 파일로 유지합니다.

        미연결 자료는 아직 음악 프로젝트 또는 보존 정책과 안전하게 대응되지 않은 자료입니다. 자동 정리는 이를 지우지 않습니다. 연결 또는 별도 정리 계획을 먼저 확인해야 합니다.

        설치되지 않았거나 대상이 없는 검사는 비활성으로 표시되어 시간과 디스크 검사를 쓰지 않습니다.

        변경 이력 안내

        이력은 변경이 실제 저장된 뒤에만 기록됩니다. 제목·가사·음원·영상 설정·검수 의견·정리 작업의 전후 요약을 펼쳐 볼 수 있습니다.

        프로젝트나 음악 그룹을 제거하면 연결된 관리 이력도 함께 삭제 계획에 포함됩니다. 완료 파일을 포함한 삭제 범위는 실행 전에 별도로 보여 줍니다.
