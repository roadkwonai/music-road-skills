# 오프닝 썸네일과 크레딧

이미지 공급자는 [호스트별 이미지 생성](../../road-music-video-studio/references/image-providers.md)을 따른다. `image_gen` 인자 설명은 ChatGPT에 해당하며 Antigravity에서는 해당 세션의 이미지 기능/참조 입력으로 연결한다.


확정된 곡명·아티스트·해당하는 그룹/멤버·작사/작곡 표기를 작은 release 카드에 고정한다. 사용자 변경을 최신 기준으로 삼고 원본 시트의 과거 그룹명이나 파일명을 현재 크레딧으로 오인하지 않는다. 없는 아티스트·멤버·기여자를 만들어 채우거나 모든 음악에 로드뮤직 크레딧을 붙이지 않는다. 제목이 없으면 파일명 기반 작업명임을 구분하고 확인된 항목만 표기한다.

선택한 인물/공간·스타일 key와 대표 장면을 참조해 `image_gen`으로 곡의 분위기에 맞는 단일 키비주얼을 만든다. 인물이 없는 연출이면 공간·소품·추상 모티프로 표지를 만들고, 인물을 넣기 위해 제작 방향을 바꾸지 않는다. 단체가 있으면 개별 누끼 대신 같은 광원·원근·접지의 통합 장면으로 생성한다. 작은 크기에서도 제목과 핵심 피사체가 읽히고 이름/크레딧이 과밀하지 않게 한다. 생성 이미지의 철자·누락과 해당 인물의 일관성을 확인한다. 편집 가능한 Showreel 타이포도 같은 확정 문구를 쓴다.

첫 프레임부터 썸네일이 보이는 짧은 오프닝으로 배치하고 곡의 첫 마디와 어울리는 카메라/와이프로 본편에 연결한다. 썸네일 구간에는 가사 glyph를 표시하지 않고, 표지가 완전히 퇴장한 다음 본편 화면에서 첫 가사를 시작한다. 처음 약 0.42초처럼 보컬이 아주 이르게 들어오면 가사를 단순히 숨겨 누락하지 말고, 독립된 인트로 시간을 확보해 원음·자막·비트·FFT·장면의 기준점을 같은 offset으로 갱신한다. 요청되거나 제작 범위 안에서 정한 오프닝 길이와 무단 추가 시간을 구분하며, 프로젝트별 실제 duration·fps·첫 가창 시각으로 길이를 정한다. 제목·멤버·제작 크레딧·자막·상시 스펙트럼이 겹쳐 읽히지 않는 구도를 피한다.

완성 썸네일 PNG/JPEG를 독립 납품하며 영상 첫 화면·포스터·검토 페이지·내보내기 메타데이터의 곡명/그룹명을 일치시킨다. 바뀐 이름 때문에 기존 음원·시트·영상의 파일을 일괄 이동하거나 덮어쓰지 않는다. 첫 화면·첫 가창·오프닝 퇴장 경계의 native 스틸과 원음 proof에서 cover 퇴장 전 가사 glyph 픽셀이 0인지 확인한 뒤 전곡을 마감한다.

오프닝 길이와 무음 여부는 최신 사용자 요청을 따른다. 특정 프로젝트의 1초 무음을 모든 곡의 기본값으로 고정하지 않는다. 무음을 요청하면 해당 구간에 음악·환경음·효과음을 임의로 채우지 않는다. 별도 요청이나 박·프레이즈 연결 근거 없이 원곡 중간을 발췌해 앞에 붙였다가 곡 처음으로 되돌리는 연결은 피한다. 원곡 PCM 보존 검사는 음악적 연결의 자연스러움에 대한 청취 검수와 구분한다.

명시적으로 요청한 음악 티저는 제목 표지와 구분해 원곡 in/out·출력 in/out·속도를 기록한다. 티저의 가사·비트·FFT는 해당 발췌 구간에 매핑하고, 원곡 처음부터 이어지는 본편의 공통 offset과 혼동하지 않는다. 보컬 티저와 표지의 무가사 조건이 겹치면 표지를 첫 보컬 전에 퇴장시키거나 표지와 티저 장면을 별도 구간으로 구성한다. 동일 구간의 가사 표시를 사용자가 명시하면 최신 요청을 우선한다.

오프닝을 줄이거나 늘리면 본편 영상·원곡·자막·비트·FFT의 시간 대응을 함께 갱신한다. 오프닝 화면만 압축할 때는 원곡의 속도·피치를 바꾸지 않는다. 기존 본편을 복사하는 부분 편집은 원본/출력 구간과 속도·offset을 편집표에 남기고, 바뀐 첫 화면·퇴장·첫 가사 경계와 전체 프레임 수·연속 PTS를 확인한다. 보존 범위는 인코딩 패킷/프레임 또는 대응 스틸, 오디오는 PCM·최종 인코딩의 대응 위치로 검증한다. 무음 PCM, 최종 오디오의 경계, 파생 SRT와 최신 검토 페이지까지 확인한다.
