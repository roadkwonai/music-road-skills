# 음악의 리듬, 화면효과와 타이포그래피

## 음악에 반응하는 화면

- 사건의 밀도·진폭·색·서체는 곡 구간과 선택한 미술 양식에 맞춘다. 강한 후렴과 조용한 프레이즈를 같은 강도로 채우지 않는다. 가창이 없는 곡에는 가사 타이포를 강제하지 않는다.
- 박·마디·히트·섹션의 사건 크기를 달리한다. 짧은 줌 반동, 화면 회전/밀림, 스프링·출렁임, 방향 전환, 리본·렌즈·입자·스펙트럼 펄스를 곡에 맞게 고른다. 모든 박에 같은 효과를 반복하지 않는다.
- 장식 사건의 시작·지속·퇴장을 편집표나 시간 함수에서 확인할 수 있게 두고, 인물과 가사가 다시 또렷해지는 구간을 실제 proof로 확인한다. '잠깐'이라는 설명만으로 퇴장 검수를 대신하지 않는다.
- 화면 전체의 회전·줌·진동은 사진을 한 평면으로 다뤄 인물과 공간을 함께 움직인다. 얼굴만 국소적으로 뒤틀지 않는다. 충분한 overscan으로 빈 모서리를 막고, 자막은 읽히는 좌표·크기를 유지한다.
- 상시 스펙트럼을 명시 요청하면 단발 효과와 분리한 지속 레이어로 만든다. 좌·우·하단 중 읽히는 위치에 두고, 실제 대역값에 반응하는 막대·리본·이중 곡선 등의 변형을 마디에 맞춰 연속적으로 연결한다. 밝은 사진에서도 획·명암·크기가 실제로 보이는지 proof로 검수한다. 고정 performer ROI나 불투명 배경판은 기본값이 아니다. 스펙트럼은 장면과 같은 미술 언어로 설계한다. 단순한 막대 배열·동그라미 손잡이·굵은 검정 테두리를 덧붙여 조작 UI처럼 보이는 경우에는 조형 자체를 바꾼다. 막대/곡선 개수나 작동 여부만으로 디자인 통과를 선언하지 않는다. 능선형에서는 전체 음량이 높이 대부분을 결정해 대역 기복이 평평해지지 않도록 각 band의 대비를 형태의 주원인으로 둔다. 흐르는 잔광이 필요하면 같은 곡선을 단순 평행 복제하기보다 짧게 지연된 실제 band 데이터를 읽어 연결한다.
- 스펙트럼은 확정 음원의 실제 주파수 대역에서 만든 고정 데이터를 쓴다. 저음·중음·고음에 반경·길이·두께·속도 등을 다르게 연결한다. 단순 사인파/난수/비트 장식을 FFT 스펙트럼이라고 부르지 않는다. 입력 해시, 대역·fps·정규화·attack/release와 끝 패딩을 기록한다.
- 무음 오프닝에서 유지하는 타이틀·파형 모양 장식은 장식 모션으로 구분한다. 소리가 없는 구간의 장식 움직임을 최종 오디오에 반응하는 FFT라고 보고하지 않는다.
- 순간적인 겹침이나 큰 동작을 모두 제거해서 임팩트까지 없애지 않는다. 밝기 반전 대신 위치·회전·스케일·기하 변화를 활용하고, 전체 화면 섬광은 초당 3회 이하로 둔다. 유리 격자·반사 바닥처럼 촘촘한 명암 무늬는 줌·회전·비트 이동만으로도 반복 점멸을 만들 수 있다. 해당 숏의 카메라 이동량과 비트 진폭을 줄이고, 다음 숏 전환에 쓰이는 이전 사진까지 포함해 검수한다. 실제 proof와 완성본에서 native qa_check의 섬광 검사와 motion_check를 확인하며 임계값은 낮추지 않는다.

## 고정 보호창보다 시간의 흐름으로 연출한다

M/V 사진은 기본 화면이다. 효과가 짧게 등장·전개·이탈한 뒤 인물과 장면이 다시 또렷하게 보이는 흐름을 만든다. 타이포나 빛·파형이 잠깐 인물을 스치는 것은 허용한다. 모든 프레임에서 모든 겹침을 없애려고 고정 얼굴/몸 보호창, 딱 잘리는 영역, 누끼 마스크를 기본 적용하지 않는다. 마스크는 연출상 필요한 장면에서만 선택한다.

큰 문구가 계속 나올 필요는 없다. 글자가 좁은 영역이나 인물 보호 경계에 잘려 읽히지 않으면 위치·크기·지속시간을 바꾸거나 그 사건을 모션그래픽·스펙트럼·전환으로 대체한다. 장식 타이포를 빼더라도 정확한 가사는 하단에서 가창에 맞춰 읽히게 한다. 장시간 불투명 배경/veil로 M/V 이미지를 덮거나 글자 창 안에서만 인물을 보여 주는 방식은 가시성을 실제로 확인한다.

## 타이포와 하단 자막

- 첨부 자막 스타일이나 전곡 통일 요청을 최우선한다. 지정한 서체·굵기·색·획·그림자를 먼저 맞추고, 임의로 구간별 다른 family/재질로 바꾸지 않는다.
- 최신 글꼴 지정·해제 요청을 우선한다. 선택을 위임받으면 곡에 맞는 확인된 OFL 서체를 고르고, 이전 Paperlogy 지정을 영구 기본값으로 고정하지 않는다. 실제 family/weight 파일과 로드를 검증하며 정적 서체를 가변 폰트로 가정하지 않는다.
- 글꼴 이름·색·그림자만 바꾸고 디자인을 끝내지 않는다. 구절의 위계, 의미 단위 줄바꿈, 획·자간·재질·크기와 조립·마스크·확장·안착·해체의 운동을 함께 설계한다. 네온·무지개·금속 그림자를 곧 화려함으로 간주하지 않는다.
- 하단 가사도 짧은 글자/어절 조립, 탄성·baseline wave, 광택 sweep, 두 톤 강조, 가는 스펙트럼 밑줄 등으로 리듬을 표현할 수 있다. 전 구절을 크게 흔들거나 전체 자막을 장시간 분해하지 말고, 정확한 전문을 읽을 시간을 남긴다. 모든 곡에 같은 서체/기법 세트를 강제하지 않는다.
- 짧은 가창 구절은 진입 완료 시간을 가용 길이에 맞춘다. 세로 reveal 때문에 읽기 시간 대부분이 잘린 글자로 남으면, 전문을 보인 채 이동·광택·탄성으로 바꾼다. 유지 시점뿐 아니라 진입 초반의 실제 glyph도 검수한다.
- 원문·띄어쓰기·순서는 보존하고, 효과를 가창 전에 미리 시작하지 않는다. 타이포의 장식용 글자 순차 애니메이션/색 강조는 실제 음절·단어 가창 timestamp와 구분한다. 근거 없는 가라오케 동기화를 주장하지 않는다.
- glyph·geometry·mask는 실제 사용하는 구절/레이아웃만 setup에 캐시한다. 사용하지 않는 모든 대형 레이아웃을 굽거나 render에서 Canvas/DOM을 반복 생성하지 않는다. Canvas 사진 활자는 실제 glyph alpha mask에 destination-in/source-in을 쓰며, fillText 뒤의 clip만으로 글자 마스크가 생기지 않는다.

## 원래 Showreel의 표현력으로 검수한다

설치 Showreel design/techniques의 입자·자모 조립(T04/05), 가변 굵기·슬램·유리 활자(T06–08), 빛줄기·비트 타일(T09/10), 펀치·아이리스·몽타주·잔상(T15/16/18/19)을 콘셉트에 맞게 변형한다. 이는 후보 원리이며 모두 구현하는 체크리스트가 아니다. 사용자 목표가 문자 퍼포먼스가 아니라 M/V의 리듬과 비트 효과라면 비문자 그래픽과 화면 움직임을 중심으로 기획한다.

효과 함수 개수, 깨끗한 스틸, 기술 검사 통과만으로 화려하고 좋은 디자인이라고 판정하지 않는다. 같은 시각의 전후 프레임, 등장→전개→이탈의 연속 띠, 약 10–15초 원음 시퀀스에서 실제 운동·무게감·가독성·인물 노출 시간을 본다. 사진 나열과 작은 모서리 장식만 늘어난 경우에는 연출을 바꾼다. 사용자에게 거절되거나 대체된 디자인은 보존하며, 기술 검수 KEEP을 사용자 취향 승인으로 해석하지 않는다. 이미 위임받은 제작을 재승인 대기로 바꾸지 않는다.
