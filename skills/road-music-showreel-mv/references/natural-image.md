# 자연스러운 인물-공간 결합

선택한 연출에서 인물이 등장할 때 적용한다. 인물 없는 작품은 공간·스타일·소품 key만 사용하며 이 문서 때문에 캐릭터·의상·군무를 추가하지 않는다. 허가된 기존 key 또는 이번 제작에서 검수한 master/의상·배경·소품 시트로 만든 한 장의 full-frame 장면을 먼저 통과시킨다. 인물만 누끼로 붙인 콜라주를 최종 장면으로 쓰지 않는다.

## 프롬프트와 검수

- 배경의 지평선·소실점·카메라 높이와 인물의 눈높이·발 크기·몸 방향을 같은 공간 좌표로 적는다.
- 서기, 앉기, 기대기, 걷기는 실제 바닥·좌면·난간·계단과 맞물리게 한다. 새 가구·지지면은 새 공간 설계에서 위치·재질·광원·접촉을 먼저 정한 경우에만 추가한다.
- 광원 방향·색온도·그림자 길이/농도·환경 반사를 배경 기준으로 맞춘다. 발·좌면과 지지면이 보이는 컷에서는 접촉 그림자와 체중 지지가 자연스러워야 한다. 얼굴 클로즈업처럼 해당 부위가 없는 구도에는 전신 기준을 강제하지 않는다.
- 전경 물체는 얕은 깊이로만 얼굴을 가리고, 인물은 전경·중경·배경의 실제 깊이 중 하나에 둔다. 단체는 같은 높이·크기·정면 일렬을 피한다.
- 생성 뒤 배경 원본과 나란히 보고 원근, 접지, 그림자, 광원, 반사, 가림, 소품 상호작용, 인물 비율을 통과/수정으로 기록한다.

유명 화보에서 빌릴 수 있는 것은 거리감·시점·빛의 관찰뿐이다. 실존 인물의 얼굴, 의상, 세트, 포즈 조합을 재현하지 않는다.

장소와 촬영 거리·각도의 변화는 음악과 사용자의 방향에 맞춰 설계한다. 몽환·판타지 공간을 요청받으면 새로운 세트 키시트를 먼저 만들고, 각 세트의 광원·바닥·지지면과 함께 인물을 다시 생성한다. 현실 스튜디오 두 곳 같은 이전 작업의 구성을 기본 제한으로 굳히지 않으며, 모든 MV에 같은 장소 수를 강제하지 않는다.

전곡 shot inventory에 각 메인 사진의 자산 경로·해시·등장 시각/간격·반복 이유를 남긴다. 같은 포즈·배경이 짧은 간격으로 반복되면 새로운 관계·시점·행동·대형·공간·렌즈의 원본 장면을 추가한다. 같은 사진의 확대·좌우 이동·반전·색 변경만으로 새 구도를 확보했다고 세지 않는다. 멀티뷰·콜라주는 여러 메인 사진으로 세지 않는다. 의도적 주제 모티브의 재등장은 유지할 수 있으나, 반복 목록과 연출상 이유를 최종 컨택트시트에서 검토한다.

후렴에 군무가 필요하면 동일한 멤버 구성과 의상 기준을 담은 단체 key 시트를 먼저 통과시키고, 새 군무 컷마다 행동·카메라·거리 또는 공간을 실제로 바꾼다. 손발·발의 접지·멤버 사이 간격과 가림이 자연스러운지를 개별적으로 확인한다.

프레이밍은 프롬프트의 의도와 생성 결과를 구분해 기록한다. 원본에서 잘린 손·발이 카메라 축소로 복구됐다고 주장하지 않는다. 실제 렌더의 얼굴 식별·표정·자막 가독성을 확인하되, 사용자가 허용한 짧은 손끝·부츠 크롭까지 없애려고 화면 움직임 전체를 정지시키지 않는다. 군무 포즈 사진과 카메라·전환 편집을 연속 안무 생성이나 립싱크 영상으로 보고하지 않는다.

다중 뷰 캐릭터 시트는 한 사람의 얼굴·의상·뒷모습을 담은 자료임을 프롬프트에 명시하고 여러 인물로 세지 않게 한다. 참조 수는 현재 호스트 도구의 실제 제한을 확인해 지킨다. 예를 들어 호출당 최대5장이면 4인 단체는 인물 마스터4장+세트1장으로 구성할 수 있다. 필요한 역할이 더 많으면 먼저 별도 키시트로 정리하며, 참조 초과를 유료 API 전환으로 해결하지 않는다.
