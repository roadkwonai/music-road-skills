# 음악별 연출과 스토리보드

이미지 공급자는 [호스트별 이미지 생성](../../road-music-video-studio/references/image-providers.md)을 따른다. `image_gen` 인자 설명은 ChatGPT에 해당하며 Antigravity에서는 해당 세션의 이미지 기능/참조 입력으로 연결한다.


신규 전곡 M/V의 기획 단계에서 읽는다. 기존 영상의 작은 수정은 해당 범위를 따른다. 장르 이름으로 템플릿을 고르는 대신 실제 곡의 전개와 사용자의 방향으로 연출을 정한다.

## 음악 한 곡에서 출발하기

음악을 주고 전체 제작을 요청하면 콘셉트·보드·필요 이미지의 설계도 위임된 것으로 본다. 기존 캐릭터나 시트가 없다는 이유로 멈추거나 모든 단계의 사용자 승인을 다시 받지 않는다. 스킬 개선·기획만 요청한 경우에는 매체를 생성하지 않는다.

- 파일의 실제 길이·샘플레이트와 기존 메타데이터를 확인한다. 가능한 분석/청취 수단으로 박·템포 변화·에너지·음색·가창/연주·가사의 정서·도입/전개/절정/종결 구간을 파악하고, 측정·제공 정보·추정을 구분한다. 파일명만으로 장르·감정·보컬 성별을 확정하지 않는다.
- 장르가 섞이거나 구간별 성격이 달라지면 구간별 강약을 설계한다. 템포만으로 연출을 고르지 않고 스트레이트/스윙/셔플/하프타임/루바토 등 박의 느낌, 음색·악기, 가창의 밀도와 감정, 섹션별 대비를 함께 본다. 빠른 템포가 항상 강한 감정인 것은 아니며, 록이라는 이유로 조용한 절까지 난폭한 컷을 쓰지 않는다. 박이 불명확하면 규칙적인 비트를 꾸며내지 말고 프레이즈·음색·에너지 변화를 큐로 쓴다.
- 가사 입력과 자막 처리는 [가사 입력 분기](vocal-caption-timing.md)를 따른다. 연주곡에는 가사나 가상의 가창 시각을 만들지 않는다. 곡명은 확인된 자료를 쓰며, 없으면 파일명 기반 작업명임을 밝힌다. 아티스트·멤버·작사/작곡자를 추정해 크레딧에 채우지 않는다.

## 연출 카드: 형태부터 결정하기

한 장의 짧은 카드에 곡 구간/근거, 핵심 정서와 시각 모티프, 주 연출 형태와 선택 이유, 미술 양식·색/질감, 인물/군무 필요 여부, 자막 정책, 효과의 강약을 고정한다. 사진·일러스트·초현실 환경·그래픽 아트 중 곡과 의도에 맞는 양식을 선택한다.

| 연출 형태 | 보드에서 전개할 것 | 필요한 이미지 기준 |
| --- | --- | --- |
| 서사형 | 인물/관계/공간의 상태가 시작→변화→전환점→종결로 이어짐 | 반복 주인공이 있을 때만 정체성·의상, 사건을 만드는 장소·소품 |
| 솔로·밴드·퍼포먼스형 | 감정·연주·무대의 변화, 시선과 손/악기의 상호작용 | 해당 인물·의상·악기/무대. 군무는 콘셉트가 요구할 때만 |
| 풍경·공간형 | 빛·날씨·거리·시점·공간 관계가 곡의 프레이즈와 함께 변함 | 공간/스타일·물성·색 기준. 사람/가수 시트는 불필요 |
| 추상·시각 모티프형 | 한 모티프의 형태·재질·밀도·색이 음악 전개에 맞춰 변주됨 | 그래픽/재질·형태 기준과 전개별 장면. 가짜 가사·임의 캐릭터 불필요 |
| 혼합형 | 서사·퍼포먼스·공간을 같은 모티프와 미술 언어로 연결 | 선택한 형태에서 실제 필요한 key만 결합 |

가수 역할의 가상 인물과 이야기 속 배우를 구분한다. 제공된 아티스트/보컬 설정을 존중하되, 목소리만으로 실제 인물의 정체성을 만들거나 여성 보컬을 곧 4인 걸그룹으로 해석하지 않는다. 인물 없는 곡에 캐릭터·의상·군무 시트를 생성하지 않는다. 아이돌 곡도 솔로·서사형일 수 있고, 연주곡도 인물 서사형일 수 있다.

| 음악의 성격 | 장면·미술·편집을 정하는 단서 |
| --- | --- |
| 트로트 — 정통·세미·댄스 등 | 가사 속 인생·관계·여정 또는 솔로 무대의 감정 전개. 발음·긴 음을 읽을 자막 시간을 남기고 리듬형에서는 악센트별 카메라/빛을 키움. 시대·색감은 요청과 곡으로 정하며 복고·과장 장식·군무를 자동 적용하지 않음 |
| 발라드 — 피아노·팝·어쿠스틱 등 | 작은 행동·표정·소품과 공간의 변화로 관계·기억·회복을 전개. 구절의 여운을 읽을 숏 길이를 두고 후렴은 거리·빛·공간 규모의 변화로 확장; 감정이 강하다고 모든 컷을 흔들지 않음 |
| 락발라드 — 록/파워 발라드 등 | 서정적인 절과 기타·드럼·가창이 커지는 구간의 대비를 보드에 반영. 감정 서사·솔로·밴드 중 곡에 맞게 선택하고 후렴에 무게 있는 카메라·컷·빛을 집중; 록이라는 이유로 전곡을 공연 무대로 만들지 않음 |

| 재즈 — 스윙·보사·퓨전 등 | 프레이즈·악기 응답·즉흥의 밀도와 여백을 공간/연주/서사로 연결. 악기 디테일과 전체 공간의 거리 변화, 섬세한 컷을 사용하며 카페·빈티지·술집을 장르의 의무로 만들지 않음 |
| 팝 — 어쿠스틱·인디·시티·신스·레트로 팝 등 | 훅·가사·사운드의 성격에 따라 서사·패션·공간·추상 미술을 선택. 명료한 시각 모티프를 변주하고 훅의 시점/색/형태 변화로 기억점을 만듦. 밝은 색·네온·그룹 무대는 세부 스타일과 요청에 맞을 때만 |
| 포크·싱어송라이터·어쿠스틱 | 목소리·악기 질감, 일상·여정·관찰의 서사. 자연스러운 행동과 거리/빛 변화를 사용하고 화려한 장식으로 구절을 덮지 않음 |
| 힙합·랩·트랩 | 화자의 시점·말의 의미·공간/소품을 연결. 플로/악센트별 컷과 짧은 키워드 사건; 전 단어를 검증 없는 가라오케로 만들지 않음 |
| 록·펑크·메탈 | 서사 또는 솔로/밴드의 연주·무대 에너지와 질감. 악기를 쓸 때 구조·손·몸의 접촉을 검수; 강한 구간에서 카메라·컷의 무게를 키움 |
| 댄스 팝·K-pop | 퍼포먼스·패션·서사·시각 모티프 중 곡에 맞는 형태. 그룹/군무가 선택됐을 때만 대형·동작·무대 key를 만들고 후렴에 배치 |

| 로파이·칠합·블루스 | 음색·스윙·생활감·여백에 맞는 관찰형 공간/연주/서사. 부드러운 패럴랙스와 질감, 프레이즈별 작은 사건을 설계하며 특정 장소·필름 효과를 강제하지 않음 |
| 클래식·오케스트라·OST | 주제 선율·악장/프레이즈·크레셴도에 맞는 서사·공간·상징 변주. 무보컬이면 가창 자막 없이 음악의 구조로 진행 |
| 앰비언트·뉴에이지·명상 | 긴 호흡의 환경·추상·빛/물성 변화. 느린 구간을 억지 진동·슬램 타이포·컷 난사로 채우지 않음 |
| 명시된 CCM·워십·종교곡 | 확정 가사와 사용 목적에 맞는 서사·공간·상징·타이포. 일반 음악을 임의로 종교 영상으로 바꾸거나 가사 의미를 개작하지 않음 |

표에 없는 장르도 같은 관찰·선택 원리로 설계한다. 사용자의 명시한 연출이 장르 통념보다 우선한다.

## 세부·혼합·새 스타일로 확장하기

장르표는 허용 목록이 아니다. 컨트리·블루그래스·국악/전통·민속·라틴·레게·아프로비트·팝페라 등 표 밖의 곡도 이름이 없다는 이유로 제작을 거절하거나 가장 가까운 아이돌 프리셋에 넣지 않는다. 이름이 불분명하면 확인 가능한 리듬·음색·감정·구조와 사용자의 표현으로 연출 근거를 남긴다. 문화·시대·악기는 확인된 맥락을 사용하고 무관한 의상·장소의 상투적 조합으로 대체하지 않는다.

혼합 장르는 한 라벨로 덮지 않고 각 특성이 들리는 구간/층을 분리한다. 예를 들어 재즈 트로트는 스윙·악기 응답과 가창/가사 정서를 함께, 국악 트랩은 실제 악기·음색과 저음/리듬의 대비를 함께, 팝페라는 가창 프레이즈와 오케스트라의 확장을 함께 검토한다. 이 역시 선택 예이며 인물·군무·전통 의상을 자동 결정하는 규칙이 아니다.

새 스타일 지침을 추가할 때는 **관찰할 음악 단서 → 연출 선택 근거 → key/장면 프롬프트 → 전곡 보드의 상태 변화 → 효과·자막의 강약 → 대표 proof의 확인점**을 기록한다. 장르명만 늘린 별도 엔진·승인 단계·고정 샷 수는 추가하지 않는다. 같은 BPM이나 같은 장르의 서로 다른 곡 두 개가 왜 다른 보드와 장면이 되는지 설명할 수 있어야 한다.

## 전곡 보드 → key → 장면 프롬프트

보드는 전곡을 덮는 시간표다. 각 샷에 `원곡/출력 in-out | 음악 큐 | 장면 의도·행동/모티프 변화 | 인물/공간·거리/각도 | key 참조·prompt ID | 실제 카메라/효과·퇴장 | 전환 | 해당 자막`을 필요한 수준으로 기록한다. 절·후렴이 없는 곡에 verse/chorus나 그룹 군무 슬롯을 억지로 만들지 않는다. 샷 수와 길이는 곡의 호흡·행동·다양성·가독성으로 정한다.

1. 선택한 미술과 인물 유무에서 필요한 key 목록만 만든다. 반복 등장 인물에는 정체성/의상, 공간형에는 공간/스타일, 소품이 전개를 이끌면 소품 기준을 둔다. 기존 허가 자산은 곡에 맞을 때 재사용한다.
2. 필요한 key를 `image_gen`으로 만들고 실제 결과를 검수한 뒤 장면 생성에 참조한다. 단체 시트·군무 key는 군무가 선택된 경우만 만들며, 풍경/추상 작품에는 만들지 않는다.
3. 장면 프롬프트는 같은 key를 쓰더라도 **행동·감정 상태/모티프 단계·장소 관계·시점·거리·빛**이 바뀌게 쓴다. 장르 이름과 'cinematic'만 바꾼 비슷한 포스터를 반복 생성하지 않는다. 미술 기준, 실제 피사체/행동, 공간·물성·광원, 구도, 연속성 제약을 적고 불필요한 글자는 후편집으로 남긴다.
4. 검수된 key를 공유하는 독립 샷은 도구 허용 범위에서 묶어 생성한다. 실제 prompt와 참조 파일, 결과 파일, key-ready/채택 상태를 보존한다. 실패한 슬롯은 기록하고 무한 재시도나 임의 유료 도구 전환으로 해결하지 않는다.

## 같은 품질 기준, 곡마다 다른 강도

장르가 바뀌어도 자산의 일관성·고유 구도·음악 사건과 실제 동작의 연결·읽히는 자막·전곡 완성도·네이티브 proof/최종 QA 기준은 유지한다. 이전 아이돌 M/V의 광택·색·서체·효과 세트를 복사하는 것을 품질 유지로 보지 않는다.

강한 음악은 강약 대비와 임팩트를, 조용한 음악은 세밀한 움직임·호흡·상태 변화를 검수한다. motion 검사 경고가 의도한 정적 구간이면 시각/음악 근거와 구간을 기록하고 경고를 그대로 보고한다. 섬광 실패를 허용하거나 기준값을 바꿔 통과시키지 않는다. 모든 곡에 상시 스펙트럼·거대 문구·화면 진동을 강제하지 않으며, 요청된 상시 스펙트럼은 선택한 미술 안에서 지속 레이어로 설계한다.

생성 인물의 연속 연기·안무·연주·립싱크를 사진과 화면효과만으로 구현했다고 주장하지 않는다. 완성도는 실제 이미지와 원음 포함 시퀀스로 검수하고, 직접 청취/정렬 등 수행하지 않은 검사는 명시한다.
