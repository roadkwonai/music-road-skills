# AI M/V 프로젝트 전체 정리

일반 캐시 정리와 달리 이 절차는 선택한 프로젝트의 영상 완성본, 애니매틱 master, 키시트·스토리보드·샷 출력, 프레임·검수 프록시, 제작 스냅샷과 중간본을 함께 지운다. 사용자가 해당 프로젝트 전체 삭제를 명시했을 때만 사용한다. 이번 요청처럼 기존 M/V 전체 정리를 이미 맡겼으면 같은 삭제 범위를 재승인받지 않는다.

1. `storage:overview`와 `storage:mv-list`에서 음악 제목·원음 SHA·검증된 프로젝트 ID·경로·용량·차단 사유를 읽는다. 같은 원음의 여러 제작 버전을 한 음악 그룹으로 검토한다. 제목이나 폴더명만으로 서로 다른 음악을 합치지 않는다.
2. `storage:maintenance-list`로 작업 폴더 전체를 스캔한다. 성공한 최신 `scanId`와 선택한 `projectIds`를 `storage:mv-preview`에 전달한다. 또는 `storage:sweep-preview`의 `mvProjectIds`로 정확한 ID만 선택한다. ID를 임의 경로로 바꿀 수 없다.
3. 영상 완성본·애니매틱 포함 여부, 외부 원음·가사와 모델/앱 보존, 현재 작업 잠금·열린 파일·파일 변경 보호와 예상 확보량을 확인한다. 원음이 삭제 루트 안에 있거나 모델/앱이 섞인 프로젝트는 차단 사유를 해결하기 전 정리하지 않는다.
4. 반환된 일회용 `planId`로 `storage:mv-cleanup --confirm` 또는 `storage:sweep-cleanup --confirm`을 실행한다. HTML은 동일한 공개 CLI 계획을 사용한다. 예전 계획을 재사용하거나 셸 삭제로 우회하지 않는다.
5. 삭제한 프로젝트·파일 수, 실제 할당량 감소와 디스크 여유 변화를 보고한다. 최소 요약과 원음 해시는 삭제 프로젝트 밖의 감사 기록에 남긴다. 원본 음악을 재확인하고 그룹 목록을 다시 읽는다. 지워진 영상이 완성본처럼 계속 제공되면 보관함의 누락 표시/등록 기록도 확인한다.

자동 일괄 정리 버튼의 기본 계획은 캐시·검증된 잔재다. 향후 다른 음악을 제작했다고 새 M/V 최종본까지 알아서 지우지 않는다. 프로젝트 전체 삭제는 해당 음악 그룹의 명시 선택으로만 추가한다.

기존 자료는 `.harness/work`의 원음·제작 계획 표지와 검증된 공유 룩 자산, 그리고 원음 검증 기록·타임라인·이미지 생성 출처가 확인된 과거 Showreel M/V 두 프로필을 지원한다. 일반 `Output` 폴더를 전부 M/V로 간주하지 않는다. 새 제작은 스킬의 표준 프로젝트 표지를 남겨 음악별 조회·전체 정리가 해당 소유 범위를 확인할 수 있게 한다.
