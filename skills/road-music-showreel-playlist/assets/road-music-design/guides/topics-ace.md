# 작업별 안내 찾기

이 페이지는 현재 하려는 일을 어떤 가이드와 스킬에서 처리하는지 연결합니다. 같은 음악이라도 음악 생성, 영상 제작, 결과 등록, 검수는 서로 다른 완료 기준을 가집니다.

![원음에서 설정 저장, 제작 스킬, 음악별 결과, 검수로 이어지는 흐름](media/production-flow.svg)

## 음악을 먼저 만들 때

ACE·YuE·YuE MLX로 음악을 만들 때는 Road Music 음악 제작 절차에서 가사·프롬프트 검토, 생성 `jobId`, 실제 음원 경로와 승인 원문을 확인합니다. 완료된 후보를 고른 뒤에만 제작실의 원음으로 연결합니다.

> [!NOTE]
> 음악 생성 완료와 영상 제작 완료는 별개입니다. 생성된 후보의 파일이 존재해도, 영상 결과·자막·스토리보드·검수 기록이 자동으로 생기지 않습니다.

## 어떤 영상 방식이 맞는지 고를 때

- 오래 듣는 표지·CD 화면: [Showreel CD](styles.md)
- 서사·장면·스토리보드 편집: [Showreel MV](studio.md)
- 가사와 비트 중심 타이포그래피: [JIZURA](jizura.md)
- 리듬·이미지·기하 그래픽: [Showreel 음악 모션그래픽](styles.md)
- LTX 2.5 감독형 MV: 이 배포 묶음 밖의 프로젝트 `road-music-mv` 절차

## 완료 자료를 확인할 때

[내 작업물](works.md)에서는 음악별로 완성 파일을 비교합니다. 감상용 ZIP과 제작자료 ZIP의 범위는 [공개 명령과 등록 계획](reference.md)에서 확인하고, 가사 싱크는 [결과 검수](review.md)에서 확정·추정·근거를 분리해 기록합니다.

## 공간·버전·문제가 걱정될 때

[저장공간 관리](storage.md)는 보호 파일과 캐시 정리 계획을, [상태](status.md)는 로컬 준비 상태와 실제 결과 상태를, [문제 해결](troubleshooting.md)은 등록·다운로드·가독성 문제의 복구 순서를 안내합니다. 스킬 버전은 설치본의 `status`·`check`에서 읽고, 새 버전이 있다는 사실만으로 설치하지 않습니다.

```prompt
이 음악은 이미 확정된 음원입니다. Showreel MV, JIZURA, Showreel 음악 모션그래픽 중 어울리는 방식을 비교해 주세요.
가사 원문은 유지하고, 완료 기준과 필요한 결과·검수 자료를 방식별로 구분해 설명해 주세요.
```
