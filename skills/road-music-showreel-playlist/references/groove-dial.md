# 그루브 다이얼 제작

`groove-dial`은 기존 5종과 함께 선택하는 리듬 CD 프리셋이다. CD 자산 장르 계획을 명시 지원하는 자체 Showreel 템플릿이며 `--style '그루브 다이얼'` 또는 `--plan`으로 제작한다. 이미지 프롬프트, 표시 질문, 원곡/자막 해시, 곡별 샘플 경계, 렌더/등록 흐름은 기존 코어를 그대로 쓴다.

## 음악과 화면을 함께 계획

레이아웃은 분절 사진 CD → 사진 셔터 → 케이스 조립 → 회전 CD/사진 카드 갤러리다. 도입은 앨범 시작 한 번만 적용한다. 본문은 음악 템포를 참고한 12~28초 사이클로 사진 뒤집기·재배치·원형 회수를 이어 가며, 실제 음악 분석의 타격음에 선·작은 위치/크기 변화가 반응한다. 전곡을 30초로 줄이거나 같은 30초 영상을 반복 재생하지 않는다.

장르 프로필의 리듬 기본값은 창작 출발점이다. 빠른 BPM의 발라드를 무조건 강하게 만들지 말고 편성·가창 밀도·섹션의 강약을 함께 판단해 `look.motionMode`를 정한다. 다음 범주 밖 음악도 `--genre` 원문과 곡 브리프를 보존해 계획한다.

| 음악 성격 | 출발 모션 | 이미지·재질 방향 예 |
|---|---|---|
| 발라드, 재즈, 보사노바, 로파이, 앰비언트, 뉴에이지 | soft | 긴 호흡의 인물/악기 사진, 창가·클럽·조용한 공간, 완만한 정착·작은 기울기 |
| 록발라드, 정통/세미 트로트, R&B, 팝, 소울, 블루스 | balanced | 편성에 맞는 솔로/밴드·공간, 실제 강박에서 사진과 선이 답하는 리듬 |
| 댄스 트로트, K-POP, 댄스팝, EDM, 디스코, 강한 록 | drive | 퍼포먼스/리허설의 역동적 사진, 더 큰 분절·스태거·짧은 정착 |
| 혼합·미등록 장르 | 곡 브리프로 결정 | 먼저 적은 장르 기본값을 참고하고 모든 장르 이름·사용자 무드를 이미지 계획에 남김 |

실제 세부 기본값은 `assets/genre-profiles.json`이다. 위 표는 모든 재즈·팝의 연출을 강제하지 않는다. 가수의 성별/인원은 기존 캐스팅 규칙을 따른다. 연주곡은 가수·가창 자막을 만들지 않는다.

재질 `variant`는 배치와 별개다. `archive`는 사용감 있는 컬러 인쇄/거친 종이, `noir`는 흑백 인화, `neon`은 낮은 조도의 반사 색, `notebook`은 부드러운 스냅/노트, `prism`은 새 아크릴·크롬이다. 장르 계획은 프로필의 팔레트·회전·재질·모션을 적용하고, 명시 look으로 선택한 항목이 우선한다. prism의 카드는 곧은 가장자리로 합성하고 낡은 종이·필름 질감을 새 이미지에 넣지 않는다. 빈티지·레트로를 원하면 해당 재질을 유지해 장르가 바뀌어도 일관된 앨범을 만들 수 있다.

```json
{"variant":"archive","motionMode":"balanced","discPeriodSeconds":8,"palette":{"paper":"#E9E0CF","ink":"#344846","light":"#F5F5EF","dark":"#131A1C","accent":"#C76A4B"},"photoDirection":"필름 사진의 자연스러운 피부와 불규칙한 프레이밍, 명시한 편성과 무드","paperDirection":"정돈되지 않은 크림 종이와 무광 인쇄 결"}
```

```bash
"$PLAYLIST_PY" "$PLAYLIST_SKILL/scripts/playlist_presets.py" plan \
  --style '그루브 다이얼' --genre '록발라드 + R&B' \
  --vocal unknown --act auto --brief '이별의 여운, 전반은 절제하고 후렴은 힘 있게' \
  --look '/절대/look.json' --display '/절대/display-options.json' \
  --out '/절대/genre-plan.json'
```

“최신 트렌드”를 요청하면 제작 시점의 실제 레퍼런스/음악 근거를 조사해 촬영·패션·소재 브리프에 반영한다. K-POP 프리셋이나 `prism` 선택 자체를 최신 유행을 조사한 증거로 보고하지 않는다. 사용자 요구와 충돌하지 않는 창작 선택은 스스로 정해 진행한다.

## 이미지 생성

`imageGeneration.assets`의 photoA/B/C/case/paper 프롬프트로 [이미지 제작](images.md)을 진행한다. photoA 생성 후 실제 참조 이미지로 B/C/케이스를 만들어 같은 인물·의상·공간을 보존한다. 다음 곡은 그 곡의 새로운 자산/아티스트를 사용한다. 장르만 바꾸고 카탈로그의 록 밴드를 자동 재사용하지 않는다. 운영 채널명·곡명·가사는 image_gen 이미지에 넣지 않는다.

새 프리셋의 실제 자산 최소 규격: 사진 3장과 바탕은 짧은 변 700px 이상이면서 사진/바탕 원본 1024×700 이상, 투명 케이스는 1024×1024 이상. 권장 사진은 1920×1080 이상. 얼굴/악기는 원형 크롭 중앙에 두고 실제 프레임에서 확인한다. minSide 검증만으로 가로·세로/얼굴 크롭까지 확인됐다고 하지 않는다.

현재 카탈로그 미리보기는 사용자가 저장을 요청한 기존 image_gen 사진과 록발라드 구간으로 만든 기능 검수다. 36개 장르의 이미지와 전곡이 이미 완성됐다는 뜻이 아니다.

## 표시·가사·곡 전환

새 제작은 공통 4항목 질문을 그대로 사용한다. 스펙트럼/대기곡/현재 곡명은 각자 `표시 / 표시 안 함 / SKIP`, 채널명은 실제 입력 또는 `SKIP`이다. 이미 받은 값은 유지하고 미응답을 SKIP으로 처리하지 않는다. 프리셋 등록·기존 설정을 보존하는 수정에서 질문을 다시 시작하지 않는다.

- 선형 스펙트럼은 최종 mix.wav의 실제 48밴드 FFT를 쓴다. 팔레트의 선/강조색과 맞추고 자막 위 영역을 확보한다. 꺼져 있으면 FFT 분석을 생략한다. 사진·선의 비트 반응은 Showreel의 광대역 타격음/에너지이며, 이를 베이스·스네어 분리 분석이라고 부르지 않는다.
- 현재 곡명과 다음 최대 5곡은 오른쪽 정보 영역에 표시한다. 현재/이전 곡은 대기 목록에서 제외하고 마지막 곡은 ‘다음 곡 없음’으로 표시한다. 정보 영역을 켜면 아트 배치를 줄여 겹침을 피한다.
- 채널명은 케이스 명판에 그린다. 빈 값이면 명판을 만들지 않는다. 긴 이름은 말줄임하고 본문 가사는 말줄임하지 않는다.
- 카드·회전 CD·도입 스탬프의 인쇄 타이포는 현재 트랙의 `title`, 선택한 `channelName`, 해당 트랙의 승인 `PLAYLIST_LYRICS` 앞 세 줄을 정적 Canvas로 합성한다. 빈 채널은 인쇄하지 않으며, 연주곡처럼 가사가 없으면 가사 인쇄도 만들지 않는다. `editorial.quotes`가 명시되면 단일 곡에는 배열, 여러 곡에는 `trackId`별 배열 객체로 해당 가사 인쇄만 바꿀 수 있다. 제목·채널·가수를 추측하거나 이미지 생성물에 텍스트를 넣지 않는다.
- 자막은 Paperlogy와 반투명 차콜 판을 사용한다. 문장 전문은 시작부터 읽히며 `cues[].words`가 있을 때만 현재 어절을 호박색으로 강조한다. 비트 모션은 최대 1.10배·±2°이고 실제 어절 구간은 바꾸지 않는다. 줄 단위 SRT는 어절 강조 없이 표시한다. 긴 문장은 실제 가창 경계로 나눈다.
- 곡 경계에서 사진 CD·케이스·카드·바탕과 곡명/대기 목록/가사를 동시에 바꾼다. 곡별 plan의 `motionMode`는 바뀔 수 있고 팔레트·재질·회전·caption 설정은 앨범 공통값을 쓴다. 다음 곡의 장르 계획도 동일 look으로 맞춘다.

```bash
"$PLAYLIST_PY" "$PLAYLIST_SKILL/scripts/playlist_presets.py" create \
  --plan '/절대/genre-plan.json' --playlist '/절대/playlist-input.json' \
  --display '/절대/display-options.json' --assets '/절대/images.json' \
  --out '/절대/새프로젝트'
"$PLAYLIST_PY" "$PLAYLIST_SKILL/scripts/playlist_presets.py" render --project '/절대/새프로젝트'
```

## 검수와 성능

한 시각의 화면은 과거 재생 여부와 무관하다. 활성 곡의 CD/케이스/카드만 비트맵으로 캐시하고 자막도 최대 3줄의 글리프만 캐시한다. 타격음은 시간 범위를 이진 탐색한다. 음악 길이·박·이미지·가사에 특정 데모의 30초 값을 복제하지 않는다.

`test_presets.py`·`test_playlists.py`는 장르/혼합/목록 밖/캐스팅/word 시계/기존 CD 호환성을 확인한다. `check-groove-template.mjs <생성 프로젝트> <새 QA 폴더>`는 등록 미리보기와 같은 2트랙 검수 프로젝트에서 시크 동일성, 정확한 곡 경계, 표시 8조합, 3단계 모션, 5종 variant 설정의 로딩·시크, 1시간 시크, 줄 자막의 어절 강조 생략을 확인한다. 이 전용 QA fixture는 서로 다른 곡의 전체 납품을 대신하지 않는다.

실제 제작은 각 원곡 전체 길이를 렌더하고 시작·후렴·각 곡 경계·끝을 확인한다. 장시간 타임라인 시크 시험을 수십 곡 전체 렌더의 메모리·속도 벤치마크로 확대하지 않는다. 모든 원본 이미지를 브라우저가 미리 디코드하므로 아주 큰 플레이리스트는 실제 기기 메모리로 검수한다. Whisper/가창 정렬의 초안·검수 범위는 자막 산출물과 미리보기 메타데이터에 보존한다.

투명 케이스의 사각 판 회귀는 `node scripts/check-case-alpha.mjs <records.js> <새 결과.json>`으로 검사한다. 생성 케이스 자체의 알파와 반사를 그대로 합성하고 불투명 사각 바탕·인공 테두리로 투명 여백을 덮지 않는다.
