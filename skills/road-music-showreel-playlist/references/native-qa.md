# 의미·다양성·동작을 실제 화면에서 검수하기

기술 검사와 미술 판단을 따로 수행한다. source SHA·자막 gate·pixel 변화·p90·섬광 통과는 곡에 어울리는 화면이라는 판정이 아니다. 검수자는 계획서만 읽지 않고 실제 style frame, 원음 proof, 동작 띠와 경계를 본다. 새 음악 Showreel은 실제 image_gen 장면 자산과 전용 썸네일이 media 기록·decode·scene draw·렌더 프레임까지 이어졌는지도 확인한다.

## 두 가지 보기

1. **음악/가사와 함께:** 이 구절과 편곡의 감정·거리·긴장·해방이 주체와 행동에 보이는가. 가사 본문이 시작부터 읽히는가. 원음 시각에 맞게 사건이 시작/정착하는가. 실제 청취하지 않았으면 이 중 청감/가창 싱크는 판정 보류한다.
2. **큰 키워드·스펙트럼 없이:** 어떤 대상/상태/공간이 바뀌었는지 설명 가능한가. 단어만 가려도 모든 장면이 같은 사진/선/원/카드라면 장면의 주된 구조를 다시 설계한다. 사용자가 단일 형태·미니멀·사진 중심을 골랐다면 그 안의 관계/재질/시점/운동 전개로 판단하며 다른 작품처럼 강제하지 않는다.

## 장면별 유지 / 고침 / 다시 만듦

| 판단 | 실제로 볼 것 |
|---|---|
| 곡 고유의 의미 | lyric/audio/user 근거와 화면의 대상·행동·감정이 연결되는가. 장르 상투어를 붙였을 뿐인가 |
| 시각적 전개 | 색/단어만 달라지는가, 주체의 기능·상태·공간/구도가 전개되는가 |
| 소재의 역할 | 이미지가 장소·질감·목표·오브젝트를 담당하는가. 지워도 같아 보이는 작은 장식인가 |
| 운동의 무게 | 진입→이동/변형→착지/정착→후속 동작이 실제 프레임 띠에서 보이는가 |
| 음악 리듬 | 작은 반응/강세/프레이즈 변화가 구별되는가. 모든 박에 같은 큰 동작이 반복되는가 |
| 전환과 반복 | 끝의 형태/시선이 다음 구도로 이어지는가. 후렴이 재인식과 새 결과를 함께 갖는가 |
| 읽기 | 본문/큰 활자/브랜드를 각각 확인했는가. 실제 축소 화면에서도 읽히는가 |
| 최약 구간 | 어느 구간이 가장 약하며 무엇을 고칠지 답했는가. 충분하면 유지 이유를 설명하는가 |

한글 조형은 곡의 표현에 필요할 때 활용하며 비문자 작품은 N/A로 남긴다. 효과 종류 수·사진 수·장면 수·style enum 교체 횟수는 합격 조건이 아니다. 조용한 곡의 읽기 정지는 음악 근거로 평가하고 정지 회피용 스캔 막대/노이즈로 채우지 않는다. motion 검사에서 `still_ratio`·`p90`·긴 정지만 남은 경우는 수치를 낮추거나 숨기지 않는다. draft는 `needs-review`로 남기고, final에는 현재 issue 전문·motion JSON SHA·음악/미술 이유·실제 frame/strip evidence를 `creative-review.json.motionReview`에 기록한다. 섬광 과다는 이유를 써도 허용하지 않는다.

## 검수 순서

- **방향 시험:** 전곡 코드보다 먼저 주요 구간의 style frame과 가장 어려운 재질/동작을 만든다. 가사 의미가 단어를 읽어야만 설명된다면 시각적 주체부터 보완한다.
- **이미지 완료 gate:** 실제 도구 호출 → workspace 자산 → media의 roles/source/prompt/SHA → decode → scene draw/texture → 해당 실제 frame의 사용 증거 → 전용 썸네일 저장 순서를 대조한다. 계획·빈 media·기하 코드만 있으면 완료로 기록하지 않는다. 사람이 이미지 없이 하라고 명시했거나 제공·승인 자산 재사용을 지정했을 때만 그 근거를 대신 기록한다.
- **동작 시험:** 핵심 사건의 직전→이동 중→정착을 0.033–0.1초 간격12–20프레임 띠로 본다. 계산한 x/y/scale/angle이 실제 draw/transform에 반영되는지 확인한다. scene 경계±3프레임, 이미지 decode/크롭, 긴 연속 효과의 초기화도 확인한다.
- **음악 proof:** 벌스/주요 후렴/다른 분위기 구간을 실제 원음으로 확인한다. 분석 사건/이미지를 제거한 동일 시각 A/B가 필요하면 실제 픽셀과 의미 변화를 분리해 기록한다. 부분 proof의 더 긴/짧은 길이로 점수만 비교하지 않는다.
- **비평 반복:** qa/critique_NN.md에 구간별 판정·수정할 대상·근거 frame을 적는다. 약한 장면은 기존 효과를 증폭하는 것으로만 해결하지 말고 주체/구도/행동을 바꾸어 같은 시각에 다시 본다.
- **독립 확인:** 최종 전 한 번은 제작 결론을 주입하지 않은 검토자에게 raw 음악·가사·시트·동작 띠와 기준을 주고 판정을 받는다. 결과를 실제 evidence와 함께 creative-review.json에 옮긴다. 기록 작성만으로 자동 all-keep를 만들지 않는다.
- **전곡 마감:** sub4/PNG·전체 디코드·길이·규격·음량·섬광과 최종 시트를 확인한다. 최종 이미지/코드/폰트가 바뀌었으면 과거 proof와 review는 현재 버전의 근거가 아니다.

[기술 품질 절차](production-quality.md)의 현재 음원 재정렬·원문 보존·로컬 onset·timeline 형식·Canvas 결정성·글자 범위·섬광 조절·캐시 서명 검증은 계속 적용한다. 기술 경고를 통과하려고 범위/임계값을 바꾸지 않는다. 본문 가사 표시검증, 자동ASR, 실제 가창 싱크와 청취 판정을 구분한다.

## 공개하는 한계

실제 보지 않은 장면/듣지 않은 소리/하지 않은 연속 재생을 완료라고 하지 않는다. 자동 변환/픽셀 변화는 구현의 증거이지 가사 해석의 정답이 아니다. 충분히 마감 가능한 작품에 선호 수정만 반복하지 말고 필수 결함과 선택 개선을 구분한다. 최종 납품은 강점·실제 보완·검수 범위·남은 문제로 보고한다.

## 전곡과 반복 후렴

전곡 시트에서는 구절의 단어뿐 아니라 행동 주체·진행 축·목표·결과가 보이는지 본다. 같은 난간 가사가 다른 시점으로 반복되더라도 붙잡음의 주체를 잃지 않는다. 추상적 면이 길/다리/도약을 뜻한다면 양쪽 발판·틈·이동·착지 같은 공간 단서가 실제로 읽혀야 한다. 후렴 변주는 색 교체보다 구조·시점·물질의 기능 변화로 확인한다.

파열 뒤 빈 공간, 하단 작은 도형과 넓은 빈 상단, 같은 도시 위 선만 바뀌는 장면이 이어지면 가장 약한 구간부터 다시 만든다. 이 기준은 특정 색·기법·이미지 수를 강제하지 않으며 실제 구도와 동작 띠에 적용한다. 전곡 end/outro의 경로는 정수 단계 갱신만으로 오래 정지하지 않게 실제 거리/부분 선 진행을 확인하고 음악의 의도한 정착은 별도로 기록한다.

장면 초반의 조립이 끝난 뒤 반주가 계속되는데 주체가 오래 멈추는지도 검사한다. 강한 구간은 도로·발판의 새 진입, 러너/열차의 계속되는 이동, 소재에 작용하는 실제 hit/onset의 힘처럼 화면 사건을 보완한다. 작은 광점만 진동시키거나 모든 장면에 같은 카메라 흔들림을 씌워 움직임 수치를 채우지 않는다.

스펙트럼 paint 검사는 무음인 0초에 막대를 강요하지 않는다. 검증된 FFT의 실제 nonzero frame 시각으로 seek해 픽셀을 확인하고, 완전 무음 데이터는 빈 스펙트럼이 맞는지 판정한다. 본체 비트 반응은 UI를 제외한 동일 시각 hit/onset A/B로 확인할 수 있다. 분석 제거 시 native beat 시계까지 없애 장면 전체 진행을 바꾸지 말고 실제 파라미터의 작용과 미술 판정을 구분한다.

음원 시각은 container PTS와 실제 파형 정렬을 구분한다. 현재 설치본 mix.py의 alimiter는 attack=3ms/latency 보정 꺼짐이며 일정한 3ms 신호 지연이 실측될 수 있다. 원곡↔준비 mix와 mix↔최종 AAC를 여러 지점에서 따로 대조하고, 확인된 처리 지연·추가 지연·누적 드리프트를 분리해 보고한다. 메타데이터가 0초라는 이유만으로 샘플 일치를 선언하거나 가사 전체를 추정 이동하지 않는다. 다른 설치본의 필터 설정은 다시 확인한다.
