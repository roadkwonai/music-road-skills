# Road Music Showreel CD

`road-music-showreel-cd`는 이전 프리셋 이름을 쓰던 작업을 유지하기 위한 호환 스킬입니다. 새 기능은 별도로 늘리지 않으며, 실제 동작은 `road-music-showreel-playlist`로 연결됩니다.

```text
$road-music-showreel-cd로 이 음악을 CD 플레이어 플레이리스트 영상으로 만들어줘.
```

위 요청은 새 스킬의 CD 프리셋 흐름으로 처리됩니다. 새 프리셋, HTML 선택, 자막·스펙트럼·대기곡 목록은 [Showreel 음악 모션그래픽](showreel-motion.md)을 사용하세요.

| 보존되는 것 | 의미 |
| --- | --- |
| 이전 스킬 이름 | 기존 프롬프트와 링크가 계속 동작 |
| 기존 스크립트·자산 경로 | 이미 만든 프로젝트의 참조를 유지 |
| 사용자 선택 | 프리셋·채널명·표시 요소를 임의로 바꾸지 않음 |
