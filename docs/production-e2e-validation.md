# 실제 음악·Showreel 통합 검증 (2026-10-19)

기존 ACE-Step 1.5 Turbo·0.6B와 설치된 Showreel로 **손바닥의 바다** 36초 음악과 1920×1080·30fps 전곡 영상을 실제 제작했다. 장면 plate·분리 종이배·전용 썸네일은 실제 `image_gen`으로 생성했다. 기본 앱·모델·라이브러리는 유지하고 별도 테스트 프로필에서 검증했다.

## 확인한 흐름

- 실제 HTML 음원 업로드·제작 설정 저장 → 네이티브 장면 구성 → draft·final 렌더 → 실제 프레임 검수 → 게시 → 재생·다운로드 → 완료 정리.
- 영상 전곡 36초 재생: 1,080프레임, dropped 0, stalled 0. 원음과 완성 음원 각각 브라우저 재생 시각 진행·음소거 해제·오류 없음 확인. 실제 헤드폰 청취 판정과 구분한다.
- 음원·영상의 한글 파일명 다운로드와 SHA-256 일치. Paperlogy 실제 로딩과 화면 가로 넘침 없음 확인.
- 같은 음악 그룹에서 사용자 요청 3건·엔진 입력 8건, 작업 17건과 결과 파일 메타를 조회했다. 집계는 하위 단계 중복을 제외한 작업 12건·성공 12건이며 미측정 검수 시간을 0으로 바꾸지 않는다. 프롬프트 원문 복사와 프로젝트별 상세 모달도 확인했다.
- 음악 생성 86.755초(초기 모델 로드 48.217초 포함), 최종 렌더 304.759초. draft와 final의 조건이 달라 평균만으로 성능 우열을 판단하지 않는다.

## 실제 발견·보완

1. 최종 음원 SHA로 미귀속 음악 생성 기록을 처음 연결하고 null 하위 기록만 귀속한다. 기존 다른 그룹 충돌·해시 읽기 실패는 완료 처리 전에 거부한다.
2. 입력과 완성 음원이 같을 때 게시가 중복 이름으로 실패하던 문제를 수정했다. Output에는 한 파일만 보관하고 원음·완성 역할 및 각각의 재생 경로를 유지한다. 화면도 SHA로 완성 역할을 숨기지 않는다.
3. 그룹 프롬프트 카드에 프로젝트명을 표시한다. 제목은 제한된 일괄 조회로 가져오고 다른 그룹 제목은 노출하지 않는다.
4. 작업 폴더 내부의 격리 프로필에서는 전체 스캔을 비활성화하고 이유를 표시한다. 스캔 저장소의 안전 경계를 낮추지 않으며 등록 프로젝트 관리·완료 정리는 계속 사용할 수 있다.
5. 장면 상단의 영문 장식과 곡명 겹침을 실제 시트 검수 후 수정했다.

CLI 실행 경로와 `music-road-skills`의 공통 HTML·게시 도구·원장·테스트·가이드에 반영했다. 배포 Release나 설치 버전 번호는 변경하지 않았다.

## 보존·정리

- Output의 물리 최종 파일은 MP3·MP4·전용 썸네일·원가사·SRT **5개, 29,226,628B (27.87MiB)**다. 원음·완성 음원 논리 참조 2개는 같은 MP3 한 파일을 사용한다.
- 렌더 중간 picture와 게시 파생 오디오 **89,780,199B (85.62MiB)** 자동 정리 확인. 초기 음악 생성 WAV 자동 압축 제거량은 이 합계에 포함하지 않았다.
- 실제 HTML 완료 정리: **272개, 할당량 538,198,016B (513.27MiB)** 제거. private 작업 폴더에는 메타·설정·검수 의견 3개만 남았다. 재미리보기는 추가 정리 불필요를 반환했다.
- 정지한 테스트 앱의 캐시·다운로드 검증 사본·생성 이미지 원본/사본 등 정확히 이 테스트가 만든 자료 **49개, 42,991,616B (41MiB)**도 정리했다. 샘플 원음 라이브러리 사본과 SQLite 프롬프트·성능·최소 감사 기록은 보존했다.
- 위 수치는 이번 테스트에서 생성·제거한 자료 합계다. 작업 전 디스크보다 그만큼 여유가 늘었다는 의미가 아니다. 최종본과 최소 기록은 새로 남는다.
- 기존 완성 파일 35개, 1,285,667,500B의 SHA-256·크기 모두 동일함을 확인했다. 기본 앱과 모델은 설치·이동·제거하지 않았다.

## 검증과 한계

최종 `npm test` **354/354**, 관련 Python **97/97**, 별도 canonical `music-road-skills` 복사본의 같은 Python **97/97** 통과. 변경 JavaScript·Python 문법 검사와 한정 독립 코드 리뷰도 통과했다. Python 3.15에서 기존 SQLite connection ResourceWarning이 일부 출력됐지만 테스트 실패는 없었다.

원가사·LRC 본문 7줄은 일치한다. 기존 Whisper large-v3-turbo ASR은 2/7줄 정확 일치, CER 15.09%이므로 가창 발음은 확정하지 않았다. 자막은 모델 LRC 기반 자동 시각이며 사람의 행별 싱크 검수는 미완료다. 저운동 경고 3건은 임계값을 변경하지 않고 실제 시트의 잔잔한 항해 연출 검토 이유와 함께 남겼다. 단일 샘플 결과를 일반 속도·품질 보장으로 해석하지 않는다.

다른 OS, YuE 재추론, Release 앱 재빌드·배포·업데이트 설치는 수행하지 않았다. skill-creator 형식 검사기는 PyYAML 미설치로 실행할 수 없어 새 의존성을 설치하지 않았고, 기존 frontmatter·참조 경로와 실행 회귀로 검증했다.
