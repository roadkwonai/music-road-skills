프리즘의 원곡 파일명은 벨루나이며, 최신 Showreel MV v5의 그룹 표기는 **VELUNE(벨루네)**입니다. 영상 안의 확정 표기를 보존했습니다.

- CD와 모션그래픽은 실제 인트로와 가사/후렴 구간을 이어 붙인 발췌입니다. 표의 시각은 각 완성 영상 컨테이너 시계입니다.
- JIZURA는 최근 완료된 3스타일 조합 미리보기 전체를 사용했습니다. 원곡 기준 47.79–62.86초 구간이며 프레임 패딩을 포함한 영상은 약 15.08초입니다.
- 본편·원음은 수정하지 않았고 새 이미지/유료 API 호출도 하지 않았습니다. 실제 발췌 영상의 전체 디코드를 검사했습니다. 직접 청취 검수나 완벽한 가창 정렬을 인증한 자료는 아닙니다.
- HTML 아래의 세부 프리셋은 화면 구조를 고르는 참고 자료이며, 위의 최근 제작 결과와 구분합니다.

샘플 갱신 시에는 해당 스킬의 최근 실제 완료본과 검수 기록을 확인한 뒤 영상/포스터, 곡명, 발췌 구간, SHA를 함께 바꿉니다. 새 버전의 Release 노트에 갱신한 샘플을 기록합니다.
