# 최근 프로젝트 샘플

[처음으로](../README.md) · [HTML 제작실](html-studio.md)

2026-10-18 확인된 최신 완성본 세 개와 기존 CD 샘플을 등록했습니다. 요청한 ‘당신이 참 좋아요’ CD 완성본은 찾지 못해 기존 ‘아직 나의 봄’을 명시적으로 유지합니다. 예전 일반 데모로 자동 대체하지 않습니다. 목록은 [examples.json](../skills/road-music-video-studio/assets/examples.json), 발췌 범위·파일 SHA·검증은 [provenance.json](../skills/road-music-video-studio/assets/examples/provenance.json)이 기준입니다.

| 형식 | 최근 프로젝트 샘플 | 길이 | 구간 |
| --- | --- | --- | --- |
| Road Music Showreel CD | [락발라드 — 아직 나의 봄](../skills/road-music-video-studio/assets/examples/showreel-cd.mp4) | 24초 | 0–12초 · 27–39초 |
| Road Music 쇼릴 MV | [벨루나 — 프리즘 (VELUNE·벨루네 MV v5)](../skills/road-music-video-studio/assets/examples/20261018-confirmed/showreel-mv-prism.mp4) | 18초 | 0–18초 |
| JIZURA 음악 스튜디오 | [벨루나 — 어디든 좋아](../skills/road-music-video-studio/assets/examples/20261018-confirmed/jizura-eodideun-joha.mp4) | 18초 | 원곡 40–58초 |
| Showreel 음악 모션그래픽 | [벨루나 — 내일로 달려](../skills/road-music-video-studio/assets/examples/20261018-confirmed/showreel-motion-tomorrow.mp4) | 24초 | 원곡 53.82–77.82초 |

프리즘의 원곡 파일명은 벨루나이며, 최신 Showreel MV v5의 그룹 표기는 **VELUNE(벨루네)**입니다. 영상 안의 확정 표기를 보존했습니다.

- CD는 인트로와 가사 구간을 이어 붙였고, 모션그래픽은 최신 전곡 리빌드의 후렴 발췌입니다. 표의 시각은 각 완성 영상 컨테이너 시계입니다.
- JIZURA는 ‘어디든 좋아’ 가사 싱크 보완본의 40–58초를 사용했습니다. 원가사와 확정되지 않은 시각의 검수 구분을 보존합니다.
- 본편·원음은 수정하지 않았고 새 이미지/유료 API 호출도 하지 않았습니다. 실제 발췌 영상의 전체 디코드를 검사했습니다. 직접 청취 검수나 완벽한 가창 정렬을 인증한 자료는 아닙니다.
- HTML 아래의 세부 프리셋은 화면 구조를 고르는 참고 자료이며, 위의 최근 제작 결과와 구분합니다.

샘플 갱신 시에는 해당 스킬의 최근 실제 완료본과 검수 기록을 확인한 뒤 영상/포스터, 곡명, 발췌 구간, SHA를 함께 바꿉니다. 새 버전의 Release 노트에 갱신한 샘플을 기록합니다.
