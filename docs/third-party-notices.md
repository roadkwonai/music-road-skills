# 원본·글꼴·데모 자산

- Showreel 템플릿/엔진 관련 원본: https://github.com/revfactory/showreel · commit `64521220a2f8e91cb9894400c48c15b7f45205d6` · MIT. 복사된 템플릿의 LICENSE.showreel을 유지한다. 엔진 자체는 별도 설치다.
- JIZURA: https://github.com/852wa/JIZURA · commit `fc16bfe43ea4a6c25a21f1caf04d17326de14f00` · MIT. 엔진은 포함하지 않으며 설치본의 LICENSE/THIRD_PARTY_NOTICES를 유지한다.
- Paperlogy·Pretendard·Noto Serif KR은 템플릿의 글꼴별 라이선스와 NOTICE를 함께 제공한다.
- 이미지와 짧은 영상은 프리셋 동작을 보여주는 제작 데모다. 미리보기의 원곡/구간과 자동 자막 검수 한계는 각 preset.json·verification.json을 따른다. 무음인 미리보기를 음악 생성 결과로 소개하지 않는다.
- generation.json의 원래 개인 파일 경로는 공개 배포에서 제거했으며 생성 도구·프롬프트·해시는 남겼다. 새 음악 제작에는 해당 곡의 새 자산을 만들고 데모를 새 생성 결과로 보고하지 않는다.
